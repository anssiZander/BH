## Social preview

### `assets/social-preview-photon-bands.png`

Project-owned 1730 x 909 preview generated with OpenAI image generation on
29 July 2026. It shows a centered black-hole shadow, a deep star field, and one
mirrored pair of spherical station bands with an open equatorial corridor. It
contains no text, logo, watermark, planet, accretion disk, hub, spokes, mast,
antenna, or dishes.

The preview is used only for Open Graph and Twitter cards. It is not sampled by
the WebGL renderer. It was reused for this branch because it already matches
the reduced one-double-band scope; no new generated image was needed.
